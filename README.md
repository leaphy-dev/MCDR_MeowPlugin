Meow MCDReforged Plugin
一个为 MCDReforged 设计的多功能插件，提供自定义消息处理、随机喵语回复等功能。

功能特性
1. 自定义消息处理器
支持两种玩家消息格式：

<[标签]玩家名> 消息内容

[标签]<玩家名> 消息内容

自动移除命令消息后缀

兼容 Bukkit 服务器

2. 随机喵语回复
支持多个文本文件存储回复句子

可配置触发正则表达式

支持优先级排序

按权重随机选择回复

3. 命令系统
!!meow about - 显示插件信息

!!meow help - 显示帮助信息

!!meow - 显示帮助信息

!!meow reload - 重新加载配置和句子文件

安装
确保已安装 MCDReforged

将插件文件放入 plugins/ 目录

重启或重载 MCDR
